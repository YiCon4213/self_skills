# Codex 应用聊天采集

这是能力驱动的可选增强，不是 Codex CLI、VS Code 插件或 Claude Code 的默认依赖。

仅在当前环境提供可列出并读取 Codex 任务或聊天的工具，或用户通过 `--include-codex-app` 显式要求尝试时执行。两项都不成立时默认静默跳过，不构成数据缺口。用户显式要求但工具不可用时，返回一条短警告并继续使用本地基线生成报告；只有实际尝试采集后，才披露应用聊天的成功、失败或窗口缺口。

在完成本地提取后，使用可用的 Codex 应用任务工具补充 `kind=chatgpt` 会话；不要解析应用内部数据库或缓存。

1. 调用 `list_threads(limit=50)`，保留所有返回元数据，不能先按标题筛选。
2. 选取每个 `updatedAt` 不早于目标日开始时间、且 `kind=chatgpt` 的会话。
3. 对每个候选调用分页 `read_thread`：每页最多 10 个 turn，每个消息最多 1000 字符；向较早 turn 翻页，直到读到目标日开始前或没有下一页。
4. 只把目标日的 turn 写入临时索引。索引完成后才按相关性筛选，并保留纳入与排除计数和理由。
5. 分别披露列表返回数、ChatGPT 候选数、已读取数、纳入数、排除数、未分页范围与窗口完整性。已经开始尝试后，如工具调用失败、单个会话读取失败，或返回恰好 50 条且最早项仍晚于目标日开始时，必须说明缺口；不得声称 Codex 应用聊天完整覆盖。

原始消息只在当前会话处理。临时索引不得包含绝对路径、账号、凭据、完整代码或私有标识。
