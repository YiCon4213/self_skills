# Notion 发布契约

## 触发条件

仅当用户明确要求发送/发布到 Notion 或传入 `--publish` 时执行。传入 `--no-notion` 时不得发布。

使用当前客户端已经授权的 Notion 连接能力，不硬编码具体 MCP 工具名，不读取或保存 token，不调用直接 REST fallback。Codex 使用已连接的 Notion 插件；Claude Code 使用用户级 Notion MCP。

## 目标

目标数据库名为 `每日 AI 记录`，属性为：

| 属性 | 类型 | review-daily-ai-work 值 |
|---|---|---|
| 标题 | title | `YYYY-MM-DD 步伐` |
| 日期 | date | `YYYY-MM-DD` |
| 类型 | select | `AI 步伐` |
| 状态 | select | `已发布` |
| 来源 | multi-select | 实际覆盖的来源 |
| 完整性 | select | `完整` 或 `部分缺失` |

先搜索数据库并读取实际 schema。没有同名数据库时，只在本次具有明确发布意图的前提下创建；存在多个同名数据库时停止并让用户选择。

## 幂等写入

唯一键是 **日期 + 类型**。

1. 查询目标日期且类型为 `AI 步伐` 的记录。
2. 不存在则创建页面并写入属性与最终报告正文。
3. 存在一条则更新原页面的属性和正文；存在则更新，不得追加重复记录。
4. 存在多条则停止，报告重复状态，不自动删除或合并。

只发布已经通过标题、三个固定核心章节、条件章节适用性、链接和隐私检查的最终 Markdown。不得发送原始日志、局部回读、代码、绝对路径、用户名、仓库名、账号或凭据。

## 失败处理

授权缺失、工具不可用、schema 不兼容或写入失败时，保留已经生成的本地 Markdown 并输出一条短警告。发布失败不得影响本地报告，也不得改用 token 脚本重试。
